## Project Overview

This is the project details of my Week 2 cybersecurity project for footprinting on NetworkWalks.com .

The project was completed using 6 tools at kali linux for gathering information about networkwalks.com to find potential exploits or vulnerabilities. Also I used Zenmap(Nmap GUI) Scanning to scan my local network to find live hosts on the network.

### Read 'WK2-Project-FINAL-Report.docx' to find more details about this Lab


## OBJECTIVES & TOOLS

The main objectives of this project is to:

- Use 'whois' to 	Find domain registration details (owner, dates, name servers).
- Use 'whatweb'	to find fingerprint of web technologies (server, CMS, plugins, IP).
- Use nslookup	to resolve the domain name to its IP address using DNS.
- Use curl -I	to read the HTTP response headers of the website.
- Use wafw00f	to detect whether a Web Application Firewall protects the site.
- Use dnsrecon	to enumerate all DNS records (NS, MX, SPF, TXT, SRV).
- Use Zenmap (Nmap GUI)	to Scan the local subnet to find live hosts, IPs and MAC addresses.
- Windows CMD	for Local IP and MAC address identification
